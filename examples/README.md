# Split-location examples (candidate only)

research-project.json is portable metadata for the code root. Preserve the investigation's
existing ID. research-locations.example.json is a host template: replace every sample path
with a verified accessible path and keep that host configuration outside distributed code.
Do not use the sample paths literally or add collections to live connector roots yet.

Existing projects without a marker/matching mapping retain legacy single-folder behavior.
For a new split project, select its research and working folders first; prepare metadata
outside the future code destination, then pass --project-file and --locations to scaffold.
The result is only code; experiment-init adds approved missing research lifecycle artifacts.
Scoped Mac acceptance is recorded in the migration Stage 3 final acceptance; release installation must still be verified separately. Examples are templates, not executed projects.
